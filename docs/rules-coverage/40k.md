# Rules coverage: Warhammer 40,000 (system `forty-k-11`)

- **Source:** the auditor's own knowledge of the 40k core rules (10th edition structure), checked against the
  11th-edition changes the repo already encodes (core stratagems from commit a90dfe5, the terrain categories
  and the 2"/5" engagement and 2"/9" coherency values in `src/systems/wh40k/rules.ts`). Sections walked: Core
  Concepts, Command phase, Movement phase, Shooting phase, attack sequence, Charge phase, Fight phase, weapon
  abilities, core abilities, core stratagems, objective control, terrain and line of sight, transports,
  aircraft, reserves, mission scoring.
- **Date:** 2026-10-08.
- **IP:** this file lists rule names and our own one-line notes about what the code does. It quotes no rules text.
- **Edition caveat:** where 10th and 11th edition may differ (engagement range, coherency, terrain, Hazardous,
  stratagem costs), the repo's 11th-edition values are kept as they are and marked "edition value, unverified".
  None of them is counted as wrong.

Status key: **automated** (the app does it), **advisory check** (the app warns, the player decides),
**manual reminder** (the app shows it at the right time, the player resolves it), **missing** (nothing).

Paths are relative to `src/`. Main files: `core/content/examples/forty-k.ts` (the data, written `fk` below),
`systems/wh40k/rules.ts`, `checks.ts`, `module.ts`, `missions.ts`. "audit" means `systems/wh40k/audit.test.ts`.

## Summary

Counts (rows above, some rules appear in two sections): **automated 70**, **advisory check 8**, **manual reminder 21**, **missing 11**.

### Fixed in this audit

1. "Engaged" was never derived (the data asked for a status nothing set). Fall Back was never offered. Normal
